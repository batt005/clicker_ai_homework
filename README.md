# Clicker AI: бот-кликер на YOLOv8

Проект из практической работы «ИИ от сбора до внедрения». Нейросеть YOLOv8 смотрит на экран с игрой «Из грязи в князи» (Яндекс Игры) и сама играет: кликает по доллару, закрывает рекламу и покупает доступные улучшения.

## Что умеет бот

1. **Закрывает рекламу.** Находит крестик (`close_ad`) и нажимает на него.
2. **Покупает улучшения.** Находит карточки магазина, определяет по яркости, хватает ли денег, и покупает самую дорогую из доступных.
3. **Кликает по доллару.** Находит главный объект (`game`) и делает серию кликов.

Приоритет такой: реклама, затем улучшения, затем клики по доллару.

## Классы модели

| id | класс | что это |
|----|-------|---------|
| 0 | `close_ad` | кнопка закрытия рекламы |
| 1 | `game` | доллар, по которому кликаем |
| 2 | `upgrade` | доступное улучшение |
| 3 | `upgrade_locked` | недоступное улучшение (затемнено) |

## Установка

Нужен Python 3.10 или новее.

```
git clone https://github.com/batt005/clicker_ai_homework.git
cd clicker_ai_homework
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск бота

1. Откройте игру в браузере: [Из грязи в князи](https://yandex.ru/games/app/iz-griazi-v-kniazi-352620). Окно с игрой должно быть на экране полностью.
2. В терминале выполните:

```
python app.py
```

3. Бот делает скриншот экрана, ищет объекты и кликает.

### Управление

| действие | как |
|----------|-----|
| **Аварийная остановка** | клавиша **Пробел** |
| Запасная остановка | резко увести мышь в левый верхний угол экрана |
| Отладка | **F9**: сохраняет `debug.png` и выводит таблицу найденных карточек (зелёные будут куплены, красные пропущены) |

Пока бот работает, ничего не печатайте: пробел срабатывает в любом окне.

### Настройка под свой экран

В начале `app.py` есть параметр `ACTIVE_SCORE` (по умолчанию 235). Это порог яркости, по которому бот решает, что карточка доступна (у недоступных текст затемнён). Если на другом мониторе бот покупает лишнее или пропускает доступное, откалибруйте:

1. Запустите `python app.py` и нажмите **F9**.
2. Посмотрите значения `score` у доступных и недоступных карточек.
3. Поставьте порог посередине между ними.
